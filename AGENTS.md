# AGENTS.md

Правила для AI coding agents при работе над проектом team-assistant.

## О проекте

1. Проект: Spring Boot REST API, Java 21, Maven.

## Процесс работы

2. Перед началом задачи изучать README.md, структуру проекта и текущее состояние Git.

3. Сборка и проверка тестов: `mvn clean package`.

4. Новые задачи реализовывать в отдельных feature-ветках, созданных от актуальной main.

5. Не вносить изменения непосредственно в main и никогда не отправлять изменения (push) в main.

6. Не выполнять merge Pull Request самостоятельно.

7. Не добавлять зависимости без обоснованной необходимости.

8. Не изменять README.md, pom.xml и .gitignore без необходимости, связанной с задачей.

9. Перед коммитом проверять git diff и запускать тесты.

10. Автор коммитов AI-агента: AI / have@no.mail.

11. Не публиковать секреты и токены.

12. При конфликтах, неоднозначностях, ошибках авторизации или неожиданных изменениях останавливаться и сообщать пользователю.

13. Не выполнять destructive Git-команды (reset --hard, force push, удаление удалённых веток) без явного разрешения пользователя.

## Работа с моделями и режимами OpenCode

14. Не фиксировать конкретные модели или уровни reasoning в файлах проекта. Пользователь самостоятельно выбирает доступную модель и уровень reasoning для каждой задачи с учётом текущего списка моделей и своих предпочтений.

15. Для задач, выполняемых через GitHub Issue, использовать двухэтапный процесс из Skill `issue-workflow`: сначала планирование в режиме Plan, затем реализация в режиме Build. Не переходить к реализации до явного подтверждения пользователем плана.

16. Уважать выбранные пользователем модель и уровень reasoning. Не пытаться самостоятельно переключать модель, режим или reasoning и не предполагать, что конкретная модель доступна.

## Общие ограничения Git и Pull Request

17. Любые изменения выполнять в отдельной ветке от актуальной `main`. Коммиты и push разрешены только в эту рабочую ветку.

18. Итог работы агента — Pull Request в `main`. Создание PR не означает разрешение на merge: проверку и слияние выполняет пользователь.
